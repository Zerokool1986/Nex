# NEX Non-Negotiables (Red Lines)

1. **NEVER** introduce a mandatory centralized cloud server or database.
2. **NEVER** introduce global consensus blockchains or speculative token mechanics into core state.
3. **NEVER** hardcode an application to a specific network transport.
4. **NEVER** allow ambient authority or bypass cryptographic capability verification.
5. **NEVER** break backward compatibility with frozen `NEX/WIRE/v1` or `NEX/WAL/v1`.
6. **NEVER** treat an application as a standalone silo with its own parallel identity or storage model.
