## 2. Permanent Design Loop Protocol

1. **Research & Benchmarking:**
   - Investigate contemporary interaction patterns (Linear, Apple, Raycast, Signal).
   - Identify relevant cognitive models.
2. **Concept & Composition:**
   - Draft spatial layouts and information hierarchies adhering to Spaces x Lenses.
   - Verify Experience Slider progressive disclosure tiers (Simple -> Standard -> Advanced -> Operator).
3. **Implementation in Primary Laboratory:**
   - Implement directly in 
ex-desktop using egui/eframe and Phosphor tokens.
   - Use Figma as an optional comparative/vector scratchpad when needed.
4. **Empirical Runtime Inspection:**
   - Launch native Windows executable (	arget/debug/nex-desktop.exe).
   - Visually test across viewports (\times 480$ through \times 1440$).
5. **Adversarial Critique & Refinement:**
   - Execute the 15 Real Human Journeys (NEX-UX-PRODUCT-MATURATION-LEDGER.md).
   - If a screen is mediocre or confusing, redesign it immediately.
